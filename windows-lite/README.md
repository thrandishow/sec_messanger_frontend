# Шифр-связь для Windows на Rust

Лёгкий клиент локального мессенджера с системными элементами Win32. Сборка состоит из одного EXE и использует TLS из Windows. Для запуска достаточно обычной учётной записи пользователя.

## Установка и вход

1. Откройте **Параметры → Система → О системе → Тип системы**. Для 64-разрядной Windows скачайте `shifr-windows-lite-x64.exe`, для 32-разрядной — `shifr-windows-lite-x86.exe`. Целевые системы — Windows 10 и 11. Файлы предварительной сборки распространяются без подписи Authenticode.
2. Запустите файл в локальной сети сервера. Введите его адрес с портом, например `192.168.1.10:8443`, ник и пароль, выданные администратором.
3. Если Windows ещё не доверяет локальному центру сертификации, нажмите **Выбрать ca.crt…** и укажите публичный сертификат, полученный от администратора. Клиент проверяет цепочку сертификатов и адрес сервера. Выбранный CA применяется внутри приложения.
4. Выберите группу или сотрудника слева. **Enter** отправляет сообщение. После подтверждения сервера текст исчезает из поля ввода. Для личного сообщения собеседник должен быть онлайн. Для перехода с другого клиента закройте его активное подключение.

В папке `%LOCALAPPDATA%\ShifrSvyazLite` сохраняются адрес, ник и путь к публичному сертификату. Пароль и cookie сессии используются только в памяти процесса.

## Переписка

Поиск работает по названию группы и нику сотрудника. Переключение чатов сохраняет черновики до закрытия приложения. **Раньше** открывает предыдущую страницу истории, **К новым** возвращает к последним сообщениям. Время указано в UTC. В памяти хранится до 100 сообщений текущего чата. Клиент подписывается на открытую группу и принимает адресованные пользователю личные сообщения.

**Файл…** позволяет отправить документ до 10 МиБ. Для скачивания выберите вложение текущей страницы в списке над полем сообщения и нажмите **Сохранить…**. При обрыве связи нажмите **Подключить**. Перед повторной отправкой проверьте историю. Управление сотрудниками, аудит и общие ресурсы доступны в веб-клиенте.

## Сборка

В Windows нужны Rust с MSVC и Visual Studio Build Tools с компонентами C++ для выбранной архитектуры. Из папки `windows-lite` выполните:

```powershell
rustup target add x86_64-pc-windows-msvc i686-pc-windows-msvc
cargo build --locked --release --target x86_64-pc-windows-msvc
cargo build --locked --release --target i686-pc-windows-msvc
```

Готовые файлы находятся в `target/<target>/release/shifr-windows.exe`. В GitHub Actions обе сборки проходят тест нативного окна, входа по HTTPS с локальным CA, истории и отправки сообщения с подтверждением по WSS на изолированном сервере.
