# Шифр-связь — frontend

Next.js/React, статическая сборка под Nginx. Бэкенд и общий Compose находятся в
соседней папке `project_back`. Запуск обоих сервисов: `bash start.sh <LAN-IP>`.

Вход по выданному администратором аккаунту; публичная регистрация закрыта.
Интерфейс включает чаты отделов, объявления, личные сообщения с историей,
вложения до 10 МиБ, полезные ресурсы, управление аккаунтами и аудит для администратора.

Первый администратор, обновление и автономный пакет:
[инструкция эксплуатации](../project_back/docs/organization.md).
Сертификаты: [руководство SRE](../project_back/docs/certificates-sre.md).

Для разработки: Node.js 24, `npm ci`, `npm run dev` при настроенном бэкенде.
`NEXT_PUBLIC_API_URL` нужен только при отдельном origin API. В Compose запросы
идут на тот же origin через Nginx. Все ассеты локальные, внешних шрифтов и CDN нет.
Проверки: `npm run check` (типы, тесты состояния и production export).

История загружается страницами по 50 сообщений; события WS объединяются по ID.
Документы скачиваются только после проверки прав API. HTTPS защищает транспорт,
но сквозного шифрования нет. Для отправки личного сообщения адресат должен быть онлайн.
