# Шифр-связь для Android, iOS, Windows, macOS и Linux

Нативный Flutter-клиент для локального сервера Шифр-связи. На телефоне список диалогов
и переписка занимают отдельные экраны. На большом экране они открыты рядом.
Клиент поддерживает личные и групповые сообщения, историю, участников, вложения
до 10 МиБ, ресурсы организации и управление аккаунтами в соответствии с ролью.

## Запуск

Установите Flutter **3.50.0 stable** (Dart 3.14) и платформенный инструментарий.
Команды выполняются в `project_front/native`:

```bash
flutter doctor -v
flutter pub get
flutter devices
flutter run -d linux
```

Для macOS или Windows замените `linux` на `macos` или `windows`. Для телефона
укажите ID устройства из `flutter devices`. Перед входом запустите сервер
из соседнего `project_back` через `./start.sh <LAN-IP>` или `./start-linux.sh <LAN-IP>`.
Приложение обращается к Nginx на том же LAN-адресе и TCP-порту 8443.

1. Подключите устройство к локальной сети сервера. Введите, например, `192.168.1.10:8443`.
2. Если локальный CA ещё не входит в доверенные для приложения, нажмите **«Выбрать сертификат CA»**
   и укажите публичный `runtime/tls/ca.crt`, полученный от администратора. Сверьте его
   отпечаток по доверенному каналу. Для нативного Linux-сервера сертификат находится в
   `~/.local/share/shifr-svyaz/runtime/tls/ca.crt`. TLS проверяет цепочку и имя сервера.
3. Войдите с выданным ником и паролем. Сессия хранится в Keychain, защищённом
   хранилище Android/Windows или Secret Service на Linux. Пароль используется при входе.
   Если хранилище ключей недоступно, сессия действует в памяти до закрытия приложения.

Для разговора выберите чат слева или нажмите кнопку с карандашом. Галочка у исходящего
сообщения означает, что сервер сохранил сообщение. Меню аватара открывает документы,
управление организацией и выход. После смены LAN-IP сервера укажите новый адрес на экране входа.

## Платформенные сборки

| Платформа | Среда | Команда |
| --- | --- | --- |
| Android | Android SDK, JDK и инструменты Gradle | `flutter build apk --debug` для локальной установки |
| iOS | macOS, Xcode, устройство или симулятор | `flutter build ios --simulator` или `flutter run -d <ID>` |
| Windows | Windows, Visual Studio с Desktop development with C++ | `flutter build windows --release` |
| macOS | macOS и полный Xcode | `flutter build macos --release` |
| Linux | Linux, GTK 3, Clang, Ninja и libsecret | `flutter build linux --release` |

Для Ubuntu нужны `clang cmake ninja-build pkg-config libgtk-3-dev libsecret-1-dev` и
заголовки стандартной библиотеки C++. Для сохранения сессии нужен запущенный
Secret Service, например GNOME Keyring, и утилита `secret-tool` из пакета
`libsecret-tools`. Без них можно войти на время работы приложения. Распространяйте Linux- и Windows-сборки
со всем содержимым каталога сборки: исполняемый файл загружает плагины и ресурсы.
Для публикации Android настройте собственную release-подпись. Для установки на
физический iPhone укажите команду подписи в Xcode и разрешите доступ к локальной сети.

## Проверки

```bash
flutter analyze
flutter test
```

Сервер обслуживает одно активное чат-подключение на аккаунт. Личные сообщения
доставляются онлайн-собеседнику. Для переписки между двумя устройствами используйте
два аккаунта. После возврата в приложение клиент переподключается и загружает историю.
